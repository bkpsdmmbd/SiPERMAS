Konfigurasi Endpoint Google Apps Script

Masukkan Web App URL dari Google Apps Script yang sudah di-deploy (Deployed as Web App - Anyone):

Panduan Memastikan Tabel Terbuat di Google Sheets:
  1. Buka Google Sheets Anda → Klik menu Ekstensi → Apps Script.
  2. Tempel seluruh kode dari Code.gs lalu klik tombol Simpan (Ctrl+S).
  3. Jika menggunakan Apps Script terpisah (script.google.com), salin ID Spreadsheet dari URL browser Google Sheets (contoh: docs.google.com/spreadsheets/d/ID_SPREADSHEET/edit) dan tempel ke CONFIG.SPREADSHEET_ID di Code.gs.
  4. Klik tombol Penerapan (Deploy) → Penerapan baru (New deployment).
  5. Pilih tipe Aplikasi Web (Web app), atur Jalankan sebagai: Saya (Me) dan Siapa yang memiliki akses: Siapa saja (Anyone).
  6. Salin URL Web App dan tempelkan di kolom input di atas, lalu klik Uji Koneksi. Tabel PENGADUAN dan ADMINS akan langsung dibuat secara otomatis!
